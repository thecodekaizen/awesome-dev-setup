# macOS Development Environment

Personal development environment for Apple Silicon Macs.

## Stack

- Ghostty
- Zsh + Starship
- Zed
- tmux
- Git + SSH signing
- Gitleaks
- mise
- Go
- Elixir/Erlang
- Python
- Node
- Java
- Docker
- Kubernetes
- PostgreSQL
- Redis

## Bootstrap

1. Install Homebrew
2. Clone this repository
3. Run `brew bundle`
4. Restore dotfiles
5. Install runtimes with mise
6. Configure SSH separately

## Security

Secrets, SSH private keys, API tokens, credentials and machine-specific configuration are intentionally excluded.
